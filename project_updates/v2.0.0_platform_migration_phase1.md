# 📋 Phase 1: Chuyển đổi Kiến trúc Nền tảng (Platform Migration)

> **Phiên bản:** 2.0.0  
> **Ngày phát hành:** 2026-05-16  
> **Nhánh:** `platform/phase-1-migration`

---

## 🎯 Mục tiêu

Chuyển đổi từ công cụ đơn lẻ (single-tool) sang kiến trúc nền tảng đa giải đấu (multi-tournament platform).

## ✅ Thay đổi chính

### 1. Thiết lập React Router
- Cài đặt `react-router-dom@6` với `BrowserRouter`.
- Cấu hình `basename` cho GitHub Pages (`/football_prediction_tool/`).

### 2. Tạo Trang Landing Page
- Thiết kế Landing Page cao cấp theo phong cách "Modern Apple".
- Hiệu ứng sân vận đấu sống động (ambient stadium effect).
- Nút "Start Predicting" dẫn tới Competition Hub.

### 3. Tạo Competition Hub
- Trang trung tâm hiển thị các giải đấu dưới dạng thẻ (Cards).
- Phân loại: Cup Competitions & League Competitions.
- WC26 mở, các giải khác "Coming Soon".

### 4. Bảo toàn Logic WC26
- Toàn bộ logic mô phỏng WC26 (vòng bảng, knock-out, penalty, recap) được giữ nguyên.
- Di chuyển vào route `/competition/wc26`.

## 📁 Cấu trúc thư mục

```
src/
  pages/
    LandingPage.tsx    ← Trang chào
    CompetitionHub.tsx ← Trung tâm giải đấu
    WC26App.tsx        ← Logic WC26 gốc
  App.tsx              ← Router chính
```

## 🔗 Luồng điều hướng

```
/ (Landing) → /hub (Hub) → /competition/wc26 (WC26)
```
