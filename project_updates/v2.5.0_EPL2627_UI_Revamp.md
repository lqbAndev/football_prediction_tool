## 3. Script Crawl Đội Hình

### File mới
- `scripts/crawl_epl_squads.js`

### Cách sử dụng
```bash
npm install axios cheerio
node scripts/crawl_epl_squads.js
```

### Tính năng
- Cào dữ liệu đội hình từ `premierleague.com/clubs/*/squad`
- Hỗ trợ retry logic (3 lần), rate limiting (2s giữa requests)
- Multi-strategy DOM parsing (JSON state, section headings, player cards, tables)
- Output: `scripts/output/epl_2627_squads.json`
- Format tương thích với `Team` type trong dự án

### Lưu ý
- Mùa 26/27 có thể chưa chính thức cập nhật trên PL website
- Script xử lý graceful fallback khi không tìm được dữ liệu
- Output JSON có thể dùng để cập nhật `teamsEPL.ts` sau

Hệ thống deploy qua Vercel. Quy trình:
